# Instagram Grayscale

A simple browser extension that turns Instagram completely grayscale to reduce visual distractions.

## Features

- 🖤 Removes Instagram's colorful appearance
- 📚 Helps reduce visual distractions while studying
- ⚡ Lightweight and simple
- 🔒 No account or personal information required

## Installation

### Microsoft Edge / Chrome

1. Download the latest extension ZIP from **Releases**.
2. Extract the ZIP to a folder.
3. Open your browser's extensions page.
4. Enable **Developer mode**.
5. Select **Load unpacked**.
6. Select the extracted `Instagram-Grayscale` folder.
7. Open Instagram.
